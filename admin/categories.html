Category Images

Set a photo for each category — just like product images, paste an image link. The photo shows on the customer categories page; empty means the emoji tile stays.

open_in_new View Categories Page

How it works

1. Paste an image link (URL only — no upload) in a category's field.  2. The preview updates as you type.  3. Press Save — it is stored in Firestore collection categories (document id = category id).  4. To remove a photo, clear the field and press Save again — the tile falls back to its emoji.
